# 2026-09-18 — Initial import to GitHub

Walkthrough Studio existed on exactly one machine, untracked, with roughly 55 MB of
capture artifacts generated this morning that had no second copy anywhere. This commit
is the backup, and the start of the repository that the Walkthrough pattern will be
presented from.

## What We Built

- First git history for the project. 172 files: the pnpm workspace, the `hub` app, the
  dual Claude/Codex plugin packaging, the docs, and the captured walkthrough artifacts
  under `apps/hub/public/walkthroughs/`.

## Key Decisions

- **Private on creation.** The Walkthrough pattern is meant to be public by the
  AI Tinkerers Doha Round 3 talk (Mon 2026-09-21) so the audience can read the source
  behind the demo, but making a repository public is not reversible in any meaningful
  sense. Imported private; the flip to public is a deliberate, separate step.
- **Artifacts are committed, not ignored.** `apps/hub/public/walkthroughs/` holds the
  real Wikipedia capture run — screenshots, catalog, personas. It is the evidence the
  pattern works on somebody else's product, not scratch output, so it belongs in the
  repository. Scratch space (`.tmp-*`, `test-results/`, `playwright-report/`,
  `*storageState.json`) stays ignored by the existing `.gitignore`.
- **`.claude/skills/walkthrough` stays a symlink.** It is relative
  (`../../plugins/walkthrough/skills/walkthrough`), so it resolves inside a fresh clone
  and the skill has exactly one source of truth.

## Known Issue Carried In

- The catalog schema here (`surfaceStatus: {desktop, mobile}`, `location`,
  `capturedAgainst`) is a newer generation than the one Openstage writes
  (`desktopStatus`/`mobileStatus`, `route`). The two cannot currently be read by the same
  dashboard. Reconciling them is what stands between Openstage and a real walk.
